I'm the creator and maintainer of **[OmniWM](https://github.com/OmniNull/OmniWM)** (3k+ stars), a Swift tiling window manager for Apple Silicon Macs with Niri-style scrolling and Hyprland-style dwindle layouts. I build tools for window management and terminal workflows, with a focus on responsiveness, reliability, and understanding how macOS works underneath.

### Open-source contributions

- **[Ghostty](https://github.com/ghostty-org/ghostty)** — GPU-accelerated terminal emulator · [2 merged PRs](https://github.com/ghostty-org/ghostty/pulls?q=is%3Apr+author%3ABarutSRB+is%3Amerged)
  - **[Fixed intermittent ~500 ms UI stalls on macOS](https://github.com/ghostty-org/ghostty/pull/14506)** — Profiled main-thread stalls that occurred during rapid window moves and focus changes. Even with `window-save-state = never`, AppKit kept snapshotting terminal windows in the background for state restoration, and that work contended with Ghostty's main thread for the WindowServer connection lock. Made the setting fully disable native window restoration, including for already-open windows on config reload. In before/after profiles, the slowest window update dropped from ~540 ms to ~23 ms, and the lock contention disappeared.
  - **[Fixed silently broken macOS library builds](https://github.com/ghostty-org/ghostty/pull/11999)** — Root-caused a toolchain incompatibility: Apple's `libtool` silently dropped misaligned Mach-O objects from Zig-built archives, stripping the core object from the x86_64 library (97 exported symbols → 4). Added a deterministic `ranlib -D` normalization step before the merge, preserving every symbol in both architecture slices.

- **[Glide](https://github.com/tmandry/glide)** — tiling window manager for macOS
  - **[Built a Niri-style scrolling layout](https://github.com/tmandry/glide/pull/129)** — Designed and implemented a new window-management mode in Rust: horizontally scrolling columns with spring-physics animations, configurable and tabbed columns, interactive mouse resizing, and edge scrolling. Iterated on the architecture with the maintainer through review, ensured the animation timer stops when nothing is moving, and landed it behind an off-by-default experimental flag with regression tests.

- **[cmux](https://github.com/manaflow-ai/cmux)** — Ghostty-based macOS terminal for AI coding agents
  - **[Root-caused macOS 27 launch crashes and missing icons](https://github.com/manaflow-ai/cmux/issues/7880#issuecomment-5561925339)** — Building on a community report that isolated comma-decimal locales as the trigger, traced the failure to embedded Ghostty applying the user's locale process-wide at startup, which trips a CoreUI bug in SF Symbol rendering. Proposed a one-line fix: pin only the numeric locale right after Ghostty initializes, so the rest of the user's locale, including in terminal shells, stays intact. The fix that shipped in cmux v0.64.23 ([#12235](https://github.com/manaflow-ai/cmux/pull/12235)) implements this approach. Also reported the CoreUI bug to Apple (FB24679653) with a 20-line SwiftUI reproducer.

- **[bobrwm](https://github.com/bobrwm/bobrwm)** — tiling window manager for macOS
  - **[Added multi-monitor retiling and fixed a window-event race](https://github.com/bobrwm/bobrwm/pull/13)** — Made display connect/disconnect trigger an automatic retile onto the new monitor layout, with a 50 ms dedup that collapses macOS's bursts of display and space notifications into a single retile. Found a latent race in the Objective-C → Zig event ring buffer: producers ran on concurrent GCD queues, but the ring was only safe for a single producer, so window events could be dropped or corrupted under load. Moved every producer onto the main thread and added a debug assertion to keep it there. A maintainer rebased the changes into main manually.
